# Sosial

**Sosial** adalah halaman "Link-in-bio" personal yang minimalis dan modern, dibangun menggunakan **Svelte 5**, **Tailwind CSS 4**, dan **GSAP**. Proyek ini berfungsi sebagai hub pusat untuk semua tautan media sosial dan portofolio pribadi.

## 🚀 Fitur Utama

- **Svelte 5**: Memanfaatkan performa dan reaktivitas terbaru dari Svelte.
- **Tailwind CSS 4**: Styling modern dengan konfigurasi yang sangat cepat.
- **GSAP Animations**: Animasi teks *scramble* yang interaktif pada saat pemuatan halaman.
- **Iconify**: Integrasi ikon yang ringan dan fleksibel.
- **Responsive Design**: Tampilan yang optimal di perangkat mobile maupun desktop.
- **Vercel Ready**: Konfigurasi siap pakai untuk deployment di platform Vercel.

## 🛠️ Tech Stack

- **Framework**: [SvelteKit](https://kit.svelte.dev/) (Svelte 5)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animation**: [GSAP](https://gsap.com/)
- **Icons**: [Iconify](https://iconify.design/)
- **Runtime/Package Manager**: [Bun](https://bun.sh/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🏃 Memulai Pengembangan

Pastikan Anda telah menginstal [Bun](https://bun.sh/) di sistem Anda.

### 1. Klon Repositori
```bash
git clone https://github.com/username/sosial.git
cd sosial
```

### 2. Instal Dependensi
```bash
bun install
```

### 3. Jalankan Server Pengembangan
```bash
bun run dev
```
Buka [http://localhost:5173](http://localhost:5173) di browser Anda.

## 📦 Build & Produksi

Untuk membuat versi produksi dari aplikasi ini:

```bash
# Build aplikasi
bun run build

# Preview hasil build
bun run preview
```
